# Changes

## 1.0.0 — 2026-11-20

First public release.

- A large icon above the nearest corpse the game lets you interact with: the Skinning icon for skinnable corpses, a bag for corpses that only hold loot, both round inside a ring from the game's own art (gold, bronze or dragon). The logo and the eight raid icons can be picked instead.
- Options page (`/cb`, or Options → AddOns → Corpse Beacon): icons, ring style, size, height, opacity, pulsing animation, 18 alert sounds, detection range, "skinnable only" filter, live preview and a 10-second test.
- The four interaction settings the addon needs are saved on first use and given back when you disable the beacon.
- Translated into English, French, German, Spanish, Italian, Portuguese, Russian, Korean, Simplified and Traditional Chinese.
